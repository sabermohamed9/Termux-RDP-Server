# 🖥️ Termux RDP Server

تشغيل خادم سطح مكتب بعيد (RDP) على هاتفك الأندرويد باستخدام Termux، بدون الحاجة إلى كمبيوتر أو صلاحيات جذر.

---

## 📋 المتطلبات
- هاتف أندرويد (7.0+)
- تطبيق Termux (من F-Droid، وليس من متجر جوجل)
- مساحة تخزين ~500 ميجابايت
- اتصال بالإنترنت (للتحميل)

---
